# Compose

Two proposals, one on procedure and one on practice, come from the same evidence. Compose one change set.

- Keep an edit only when its moment is real: open the transcript at that entry and confirm it.
- When both propose the same fix, keep the clearer form, in the cheaper place.
- When they conflict, the evidence decides. When it cannot, drop both.
- Prefer one sharp rule over two soft ones. Prefer an edit to an existing playbook over a new file.
- Each edit targets one signal. Two edits on one signal on one night make both `confounded`, so keep the stronger one.
- At most 3 file edits per night. Code proposals do not count: they go to the owner.
