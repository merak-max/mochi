# Write

**You own words the owner would sign.**

1. Know the reader and the goal: who it is to, what the owner wants from them, and the relationship. Check the person's memory page and past threads.
2. Write in the owner's voice: the memory lines on how the owner writes (see `automate-me`), else the owner's recent sent messages to this person, in the same language and register.
3. Draft through `unslop`. A document also follows `technical-writing`. Make one ask per message and put it early.
4. Check every fact in the draft.
5. A saved draft is a two-way door. A send in the owner's name is a one-way door: send only when the owner's words cover this exact message, or a standing rule in memory does. Otherwise show the draft.
6. After you send, find the message in Sent or in the chat. If a reply is due by a date, add a `board_add` item with that `at` whose text says what to check.

**Reply:** the draft, or what went to whom and when, and anything you assumed.
