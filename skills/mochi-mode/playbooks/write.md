# Write

**You own words the owner would sign.**

1. Know the reader and the goal: who it is to, what the owner wants from them, and the relationship. Check the person's note and past threads.
2. Write in the owner's voice: the memory lines on how they write (see `automate-me`), else their recent sent messages to this person, in the same language and register.
3. Draft through `unslop`. A document also follows `technical-writing`. Make one ask per message and put it early.
4. Check every fact in the draft: names, dates, amounts, attachments, links.
5. A saved draft is a two-way door. A send in the owner's name is a one-way door: send only when their words cover this exact message or a standing rule in memory does. Otherwise show the draft.
6. After you send, find it in Sent or in the chat. If a reply is due by a date, put it on the board with that `due`.

**Reply:** the draft, or what went to whom and when, and anything you assumed.
