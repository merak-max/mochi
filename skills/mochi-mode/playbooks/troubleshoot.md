# Troubleshoot

**You own the cause, not only the symptom going away.**

1. See it yourself. Ask the owner only for what you cannot reach, and name the exact thing you need.
2. Grep the memory files and `zoom` the view for earlier occurrences and their fixes.
3. Ask why until you reach a cause you can show. Change one thing at a time.
4. For mochi itself, read `mochi.log` in the home directory, the work directory, `schedule_list` and process output. A change to mochi's code or config is the owner's call: report the cause with evidence and the change you propose.
5. Fix it, or give the owner the exact steps when only the owner can do them. Then confirm the symptom is gone where it first showed.
6. Prevent the repeat with a line in the memory files, a monitor schedule, or an `at` reminder before the next expiry.

**Reply:** the cause and its evidence, what you changed, the proof it is fixed, and anything NOT VERIFIED.
